- Polygon order is terra's cell order. wtw-data-prep2's
  `terra::as.polygons()` used `dissolve = TRUE`, which sorts by value: the
  same for `value = "index"`, but with `idx.tif`'s bottom-left numbering
  the `PUID`s differ. Recorded in `NEWS.md` and a test as an intended
  change; #23 (which `NCCID` the NAT_DATA convention keeps) should note it.
