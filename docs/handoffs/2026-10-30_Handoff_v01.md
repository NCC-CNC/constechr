## Completed

- Issue #142 (this PR): a multi-feature AOI is dissolved through
  `read_aoi()` (inside `create_1km_grid()`) with a message naming how many
  features; `aoi_file` is the returned `aoi`. ADR 0026 (decision 2) and
  ADR 0018 amended. `DESCRIPTION` 0.3.0 and a `NEWS.md` 0.3.0 heading; a
  minor release, not 0.2.1, since a documented result changes (ADR 0004).

## Current state

  features to `create_1km_grid()`, which already dissolved them, and now
  writes `grid$aoi` instead of the input feature.
- A shapefile `aoi.shp` holds GDAL's placeholder field `FID` (`N`, no
  decimals, value 0); a GeoPackage gets no attribute fields. Pinned in a
  test.
- The shapefile writer reorders a counter-clockwise ring (bounds), so tests
  compare `aoi.shp` with `sf::st_equals()`, not vertex by vertex.
- The rocker/geospatial pin is 4.6.1, on the current R minor version.
