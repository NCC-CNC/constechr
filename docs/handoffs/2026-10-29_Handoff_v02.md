## Completed

- This PR (Closes #104): `read_layer(x, layer = NULL, ...)` in a new
  `R/vector.R` (family `vector`, "Vector layers" section in
  `_pkgdown.yml`). The checks and errors of the old `read_aoi_file()`
  moved into the internal `read_vector_layer()`, shared by both functions;
  `read_aoi_file()` is now a thin wrapper that splits `<path>/<layer>`.
  `read_aoi()` on a multi-layer source without a layer reads the first
  layer with a message instead of erroring.
