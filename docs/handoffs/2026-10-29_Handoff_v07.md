## Current state

- Gotcha: `terra::as.polygons(dissolve = TRUE)` rounds values (its `round`
  argument defaults to `TRUE`, `digits = 0`, so 1.5 merges with 2) and
  compares them in single precision (0.1 comes back as 0.10000000149, and
  1 and 1 + 1e-12 merge). So `polygonize_raster()` polygonizes integer
  codes of the exact, sorted distinct values and maps them back. Values are
  exact and in the stored type (ADR 0019); a test covers it.
- The geometry column with `dissolve = TRUE` can mix `POLYGON` and
  `MULTIPOLYGON` (an `sfc_GEOMETRY`), as terra returns it; not cast.
