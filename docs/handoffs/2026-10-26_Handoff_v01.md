  matrix `clip_rij_matrix()` returns for the same AOI raster and template;
  the extent is the AOI raster's, cut to the template; values are 0 in AOI
  cells with no stored value and `NA` elsewhere, not rounded.
- An `rij` with no rows is an error (terra 1.9.34 has no raster without
  layers), not `NULL` as in `rij_to_raster()`. For #21:
  `extract_layers()` should check `nrow()` after `clip_rij_matrix()` drops
  empty rows, and skip the layer.
- The output grid is built at the cropped extent, so a national template is
  not filled per layer as wtw-data-prep2 did.
- One-off local check on NAT_DATA_20261009 and the mb_prairie AOI:
  `KBA_Percent.tif` (1 layer) and `nsc_end.rds` (5 layers), clipped and
  rebuilt on the cropped `pu_1km.tif` (324 x 351 cells, under 2 seconds
  each), are identical to `rij_to_raster()`'s rasters before rounding; the
  aligned full-grid `pu_1km_align.tif` gives the same values once cropped.
