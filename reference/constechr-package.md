# constechr: Shared Functions for Conservation Technology Tools

Functions shared by Conservation Technology (ConsTech) apps and
pipelines to prepare and extract conservation data, such as aligning an
area of interest to the national 1 km grid and extracting national data
for it. Each function documents the method it uses, so results are
consistent and repeatable across tools.
